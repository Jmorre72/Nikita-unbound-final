Bezoeken per land

Landen worden enkel geregistreerd wanneer de site op Cloudflare Pages draait. Op andere hosting telt een bezoek gewoon mee, maar zonder land.

Wie er kan inloggen op dit beheerpaneel, wordt rechtstreeks in Supabase beheerd — niet op deze pagina. Dat is een bewuste, veilige keuze: een nieuwe beheerder aanmaken vanuit de website zelf zou betekenen dat iedereen die de site bezoekt in theorie een account zou kunnen aanmaken, met toegang tot alle contracten en persoonsgegevens. Door dit via het Supabase-dashboard te doen, bepaal jij als enige wie er toegang krijgt.

Nieuwe beheerder toevoegen

Ga naar je Supabase-project

Open supabase.com, log in, en open het project van Nikita Unbound.

Authentication → Users → Add user

Vul het e-mailadres en wachtwoord van de nieuwe beheerder in, en vink Auto Confirm User aan.

Klaar

Die persoon kan meteen inloggen op admin.html met die gegevens — met exact dezelfde volledige toegang als jij.

Toegang intrekken

Ga naar Authentication → Users, klik op de betreffende gebruiker, en kies Delete user. Die persoon kan dan niet meer inloggen.

Waarom geen lijst van huidige beheerders hier? Om diezelfde veiligheidsreden kan de website zelf niet opvragen wie er allemaal een account heeft — enkel via het Supabase-dashboard (Authentication → Users) zie je de volledige lijst.
